# 平台适配

## 电子科技大学党课

| 项目 | 当前实现 |
|---|---|
| 域名 | `dxpx.uestc.edu.cn` |
| 播放路径 | `/jjfz/play` |
| 视频 | `#player video` |
| 启动按钮 | `#player .xgplayer-start` |
| 课程链接 | `.right-card a`，其中需要包含 `.vitem` |
| 当前课程 | 包含 `.vitem.active` 的链接 |
| 下一课 | 当前课程链接的后一个有效课程链接 |
| 跳转条件 | 视频触发 `ended`，下一课保持同源且路径为 `/jjfz/play` |

这些选择器来自用户提供的原脚本，并非已经重新验证过的线上结构。修改课程列表选择器前，请对照实际页面检查。

## 新平台适配步骤

1. 先检查普通 `video` 元素能否控制倍速。
2. 确认平台使用 URL 跳转还是原页面切换课程。
3. 明确当前课、下一课和末课的判断规则。
4. 为新平台添加独立的域名和路径匹配，不直接扩大现有电子科大规则。
5. 验证正常连播、最后一课、暂停、页面换源及浏览器限制自动播放的情况。

文档中的预留位置不由脚本读取；完成适配需要修改实际代码。
