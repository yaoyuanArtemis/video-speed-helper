# 视频加速助手【自动连播】｜最高16倍速｜网课·党课·考试备考

专注于【视频加速】的轻量工具，面向常见 HTML5（H5）视频播放器。安装即用，简洁面板轻松调速，支持 **0.25～16 倍自定义速度**，**1×、8×、16× 一键切换**，自动记住倍速设置。适合大学生网课复习、党课学习与考试备考课程。**自动连播目前仅适配电子科大党课页面**，其它平台待适配；实际兼容性受网站和浏览器限制。

## 功能

- 输入自定义倍速，或点击加减按钮，每次调整 0.25 倍。
- 点击 **1×、8×、16×** 快速切换。
- 保存倍速，下次打开视频时恢复。
- 处理普通 HTML5 视频，包括页面稍后加载的视频。
- 没有视频时隐藏面板。
- 在已适配的电子科大课程页，视频自然结束后按右侧课程列表进入下一课，直到最后一课。

## 使用方法

安装并启用脚本后，打开视频页面，在右下角面板操作。默认 1.5 倍，输入数字后按 Tab 或点击其它位置生效。

为避免多个脚本反复覆盖倍速，请停用其它同时控制视频倍速的脚本。

## 适用范围

通用倍速功能针对网页中的普通 `<video>` 元素，是否生效受播放器、网站和浏览器限制。

自动连播仅针对 `dxpx.uestc.edu.cn/jjfz/play` 顶层课程页面。视频自然结束后，脚本读取右侧课程列表，定位当前课程及下一课，然后跳转。没有下一课、找不到当前项或下一课地址不符合预期时，不会跳转。

暂停不会触发下一课。开始播放后停止启动重试，不会持续强制恢复播放。

## 已知限制

- 浏览器可能阻止自动播放，首次可能需要点击页面或按键。自动启动尝试最长 30 秒。
- 网站可能覆盖倍速；本版不包含复杂的网站属性拦截与兼容层。
- 未适配 Shadow DOM 内的视频，也没有通用的“下一集”识别。
- 视频全屏时，网页上的面板可能不可见。
- 8 倍、16 倍下的画面、声音及平台计时结果取决于浏览器、媒体与平台。
- 电子科大连播沿用原脚本的页面选择器，网站改版后可能需要更新；尚未完成真实课程验证。

本脚本不修改平台学习记录、签到、答题或服务端计时，也不承诺倍速播放能够计入课程完成进度。

## 数据与权限

仅使用 `GM_getValue`、`GM_setValue` 在油猴中保存倍速。没有额外的数据上传、广告、统计、远程助手或第三方界面组件依赖。
