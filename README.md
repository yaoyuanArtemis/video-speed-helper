# Video Speed Helper · 视频倍速助手

一个便于阅读和修改的轻量油猴脚本，主要用于课程视频的倍速播放。提供 **0.25～16 倍速、网页控制面板、倍速记忆**，并保留电子科技大学党课课程的自动连播逻辑。

应用场景包括电子科技大学党课和公务员党课。公务员党课平台网址暂未确定，已预留补充位置；当前不会把尚未验证的平台写成已支持。

**[安装脚本](https://raw.githubusercontent.com/yaoyuanArtemis/video-speed-helper/main/video-speed.user.js)** · [适用平台与待补充项](docs/platforms.md) · [代码导读](docs/code-guide.md) · [提交问题](https://github.com/yaoyuanArtemis/video-speed-helper/issues)

![倍速控制面板，包含正常速度、8倍和16倍按钮](docs/panel.png)

## 功能

- 在页面右下角显示倍速面板，可输入 0.25～16 之间的数字。
- 使用加减按钮每次调整 0.25 倍，或点击 **1×、8×、16×** 快速切换。
- 通过油猴保存倍速，下次打开视频时恢复。
- 识别页面已有及后来加载的普通 `<video>` 元素。
- 在已适配的电子科大课程页，尝试自动开始播放，并在视频自然结束后依次进入下一课，直到列表末尾。
- 没有视频时隐藏面板；不包含截图、下载、推荐区、远程助手或第三方界面组件库。

## 使用场景和支持范围

| 场景 | 平台网址 | 倍速 | 自动连播 |
|---|---|---|---|
| 电子科技大学党课 | `dxpx.uestc.edu.cn/jjfz/play` | 通用实现，待实际课程验证 | 已实现原页面适配，待实站验证 |
| 公务员党课 | **待补充** | 平台明确后验证 | 待补充平台和课程列表适配 |
| 其它课程视频网站 | 普通 HTML5 视频页面 | 可尝试使用，受网站和浏览器限制 | 未适配 |

本脚本调整浏览器内的视频播放，不修改平台学习记录、签到、答题或服务端计时。倍速播放是否被平台计入课程进度，由平台自身规则决定。

## 安装与使用

1. 安装浏览器扩展 [Tampermonkey](https://www.tampermonkey.net/)。
2. 打开上方“安装脚本”链接，在油猴安装页确认安装。
3. 停用旧版 h5player 或其它同时调整倍速的脚本，避免相互覆盖。
4. 打开视频页面，使用右下角面板操作。输入倍速后按 Tab 或点击其它位置生效。

默认倍速为 **1.5 倍**。设置会记住，页面中的多个视频共用同一个倍速；不同标签页之间不实时同步。

如果安装链接仅显示源码，可以在油猴中新建脚本，复制 [video-speed.user.js](video-speed.user.js) 的全部内容并保存。

### 电子科大自动连播

```text
进入课程页 → 尝试开始播放 → 当前视频自然结束
          → 根据右侧课程列表进入下一课 → 新页面继续播放
```

- 仅在 `dxpx.uestc.edu.cn/jjfz/play` 的顶层页面启用。
- 找不到当前课程或下一课、已到最后一课时停止跳转。
- 暂停不会触发下一课，开始播放后不会持续强制恢复播放。
- 浏览器阻止自动播放时，可能需要先点击页面或按键。启动尝试最长持续 30 秒。

## 已知限制

- 网站可能覆盖倍速；本版没有原 h5player 的复杂属性拦截和网站兼容层。
- 没有适配 Shadow DOM 内的视频；嵌入页面是否生效取决于油猴的执行权限。
- 浏览器视频全屏时，网页上的面板可能不可见。
- 8 倍和 16 倍是否正常播放、有无声音，取决于浏览器、媒体和网站。
- 电子科大连播依赖原页面的选择器，网站改版后可能需要更新。
- 尚未在电子科大和公务员党课真实课程中完成实测。
